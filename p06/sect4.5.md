# Section 4.5: Ad-Hoc vs. Professional

Summary By Haasini Y.

# Question 1

The paper discusses how the students in the study lacked exposure to tools and skills used in industry, such as Agile software development, Github, and testing code. Personally, it was a mix, as I learned industry-relevant tools earlier but still lack a complete understanding of basic industry-wide practices. I gained exposure to Github from high school, where my AP CS classes required us to push code to a repository for those in the group to have access and update as needed. Additionally, the lower division CS classes required us to use Git commands to create a directory, clone a repository, and push as needed. I agree with the paper, because Github did become a go-to portfolio for recruiters to go through and see someone's qualifications, and the concept of version control for code is an integral part of software development in current industry. Through college, students should obtain experience in platforms and skills vital for industry to better prepare them for internships and jobs, therefore, spending more time improving their technical skills.

# Question 2

Developers found version-control for code a foreign concept, as many computing courses did not teach them about Github. They often stressed the importance of knowing how to use a code management tool, as much of software development is heavily dependent on updating and sharing code with a team. Another concept that developers were unaware of was Agile software development practices, where, for example, larger projects are broken into smaller goals and are completed within a time set for a "sprint". Testing was also not discussed in college, since students were often told to program the solution rather than using unit tests to check if the code was working.

# Question 3

In order for students to better prepare themselves, students should work on team projects based on software development, like research teams or hackathons, to learn about version control tools and Agile software development practices. As mentioned in the paper, the best method that encompasses version control, Agile software development practices, and testing would be getting an internship at a company regardless of size. Whether you work at a start-up or well-established company, there will always be a team of people you have to work with, where you work on a codebase, have regular deadlines, and learn firsthand how Agile workflows shape the production of professional software.
